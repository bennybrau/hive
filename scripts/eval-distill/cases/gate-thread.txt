assistant: # ADHOC-41F2: Slack notice when a ticket changes state

The factory tells the team in #factory when a ticket moves (planned, approved, in review, merged, failed).

## Changes
- `apps/api/src/notify/slack.ts`: a `postStatus(ticket, status)` that calls `chat.postMessage` on the channel from `SLACK_CHANNEL`, with the ticket key, its title, the new status and a link to the run.
- `apps/api/src/runs/transitions.ts`: call `postStatus` after every state change is committed.
- Retry a failed post twice with backoff; never block the transition on Slack.

## Tests
- Unit test for the message text per status.
- A transition test with a fake Slack client: one post per state change.

## Not doing
