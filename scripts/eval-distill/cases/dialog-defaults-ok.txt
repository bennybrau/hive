Still needed: there is no `on_memory_write`, `reviewed` or `review_signal` anywhere in the repo. I checked the pinned Hermes (`66605471e9f`): the review fork is built with `skip_memory=True` (`agent/background_review.py:926`), so its `_memory_manager` is None and `inline_tool_executors._memory` (line 153) never mirrors its writes. - Add a review-done hook: after `summarize_background_review_actions`, call an optional `MemoryProvider.on_background_review(session_id, actions)`. The actions include skill edits.
